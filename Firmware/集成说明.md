# Firmware 集成说明

本目录提供**与 CubeMX 解耦的应用层源码**（`App/`）。你先用 STM32CubeMX 生成
HAL 工程（按《CubeMX配置清单.md》），再把 `App/` 接进去即可编译、烧录、调试。

## 一、目录结构
```
Firmware/
├── App/
│   ├── Inc/        # 应用层头文件（app_config.h 集中引脚与参数）
│   └── Src/        # BSP 驱动 + 计步算法 + 菜单 + 协议 + 四大任务
├── Core/           # CubeMX 生成（main.c / stm32f1xx_it.c 等）
├── Drivers/        # CubeMX 生成（HAL 库）
├── FreeRTOS/       # CubeMX 生成（Middlewares/FreeRTOS）
├── CubeMX配置清单.md
└── 集成说明.md
```

## 二、把 App 接入 CubeIDE 工程
1. 将 `App/Inc` 加入头文件搜索路径：
   工程右键 → Properties → C/C++ Build → Settings → MCU GCC Compiler → Include paths，
   添加 `../App/Inc`。
2. 将 `App/Src` 加入源文件编译：把 `App` 文件夹拖入工程，或在
   Source Location 中添加 `App/Src`（确保不是 Excluded from build）。

## 三、main.c 需要补的两处调用
在 `main()` 中，**所有 `MX_xxx_Init()` 之后、启动调度器之前**插入：

```c
/* USER CODE BEGIN 2 */
App_Init();          /* 初始化 OLED/MPU/编码器/RTC，载入 Flash 步数 */
App_CreateTasks();   /* 创建互斥锁、信号量与四大任务 */
/* USER CODE END 2 */
```

记得在 `/* USER CODE BEGIN Includes */` 加 `#include "app_tasks.h"`。

### 关于调度器启动（两种情况）
- **若用 CubeMX 的 CMSIS-RTOS（main 里有 `osKernelInitialize/osKernelStart`）**：
  保留它即可；把上面的 `App_Init(); App_CreateTasks();` 放在 `osKernelStart()`
  之前。可在 CubeMX 里删掉 defaultTask，避免空任务。
- **若不用 CMSIS、纯原生**：在 `App_CreateTasks()` 之后调用 `vTaskStartScheduler();`。

## 四、中断回调说明
`app_tasks.c` 已实现以下 HAL 弱回调，**无需在别处重复定义**：
- `HAL_UART_RxCpltCallback` —— 蓝牙单字节接收 → 协议解析。
- `HAL_GPIO_EXTI_Callback` —— 编码器按键 / MPU 抬腕中断 → 刷新活动时间（兼 STOP 唤醒）。

## 五、硬件接线表（面包板）
| 模块 | 引脚 → STM32 |
| :-- | :-- |
| OLED（软件 I2C） | SCL→PB10，SDA→PB11，VCC→3.3V，GND→GND |
| MPU6050（硬件 I2C1） | SCL→PB6，SDA→PB7，INT→PA4，VCC→3.3V，GND→GND |
| EC11 编码器 | A→PA0，B→PA1，按键→PB12，公共端→GND |
| JDY-31 蓝牙 | 模块 RXD→PA2(TX)，TXD→PA3(RX)，VCC→3.3V/5V，GND→GND |
| 一键开机维持 | PA8 → NPN 基极支路（详见硬件原理图） |

## 六、常见坑位提示
- **1.3" OLED 多为 SH1106**：`bsp_oled.h` 默认 `OLED_COL_OFFSET=2`；若你的屏是
  0.96"（SSD1306）显示左右错位，把它改成 `0`，并把初始化里的电荷泵命令
  `0xAD/0x8B` 换成 `0x8D/0x14`。
- **字库**：`oled_font.h` 为 6x8 ASCII，够显示时间/数字/英文；中文或大号时间
  请用 PCtoLCD2002 取模后替换，驱动逻辑不用动。
- **FreeRTOS 时基**：务必把 HAL Timebase 从 SysTick 改到 TIM4，否则会与
  FreeRTOS 抢 SysTick。
- **STOP 低功耗**：当前为基础框架（进 STOP + 唤醒重配时钟）。若要极致功耗，
  再启用 FreeRTOS **tickless idle**（`configUSE_TICKLESS_IDLE=1`）。
- **printf/snprintf**：用到整数格式（`%d/%lu`），newlib-nano 默认支持；
  无需勾选 float-with-printf。

## 七、VSCode + CMake 集成（本项目采用的工具链）

CubeMX 以 **Toolchain=CMake** 生成后，`Firmware/` 下会多出：顶层 `CMakeLists.txt`、
`cmake/`（含 `gcc-arm-none-eabi.cmake` 工具链文件）、`Core/`、`Drivers/`、
`Middlewares/`、链接脚本 `STM32F103C8TX_FLASH.ld`、`startup_stm32f103xb.s`。

### 1. 把 App/ 加进 CMake 编译
打开顶层 `Firmware/CMakeLists.txt`，找到用户自定义区（通常有注释
`# Add user sources here` / `# Add user defined include directories`），加入：

```cmake
# ==== SmartWatch 应用层 ====
file(GLOB_RECURSE APP_SOURCES ${CMAKE_SOURCE_DIR}/App/Src/*.c)
target_sources(${CMAKE_PROJECT_NAME} PRIVATE ${APP_SOURCES})
target_include_directories(${CMAKE_PROJECT_NAME} PRIVATE ${CMAKE_SOURCE_DIR}/App/Inc)
```

> 不要改 `cmake/stm32cubemx/CMakeLists.txt`（那是 CubeMX 托管、重新生成会被覆盖）。
> 顶层 `CMakeLists.txt` 的用户区在重新 Generate 时会保留。

### 2. main.c 补两处调用
同第三节：在 `MX_xxx_Init()` 之后加 `App_Init(); App_CreateTasks();`，
并 `#include "app_tasks.h"`。若用 CMSIS-RTOS，把这两句放在 `osKernelStart()` 之前。

### 3. 编译
```bash
cd Firmware
cmake -B build -G Ninja -DCMAKE_TOOLCHAIN_FILE=cmake/gcc-arm-none-eabi.cmake
cmake --build build
```
（新版 CubeMX 会生成 `CMakePresets.json`，则可直接 `cmake --preset Debug && cmake --build --preset Debug`。
用 VSCode 时装 **CMake Tools** 扩展，Kit 选该 gcc-arm-none-eabi 工具链文件即可一键 Build。）

产物：`build/SmartWatch.elf`（及 `.hex/.bin`）。

### 4. 烧录（ST-Link + OpenOCD）
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
        -c "program build/SmartWatch.elf verify reset exit"
```
（你环境里的 xpack-openocd 0.12.0 已含这些 cfg；若 ST-Link 识别不到，把
`interface/stlink.cfg` 换成 `interface/stlink-v2.cfg`。）
